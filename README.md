# TicketsSA

Marketplace for events, stays, experiences, equipment and merchandise in South Africa.

- **Frontend:** static HTML/CSS/JS in `frontend/`
- **Data + auth + photo storage:** Supabase (one-off setup in `supabase/setup.sql`)
- **Emails:** Netlify Functions in `netlify/functions/` (sent through Resend)
- **Hosting:** Netlify (`netlify.toml`)

See **RUNNING-LOCALLY.md** for running it, testing it, and deploying.
